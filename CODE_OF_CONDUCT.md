# Code of Conduct

We want this project to be a place where people can ask questions, report bugs and propose changes without being
treated badly. This applies to issues, pull requests, discussions and any other space run by the project.

## What we expect

- Be respectful. Disagree with ideas, not with people.
- Assume good faith, and say what you need clearly.
- Accept feedback gracefully and give it kindly.
- Keep to the topic. The project is a code library, not a place for personal or political arguments.

## What is not acceptable

- Harassment, insults, threats or discrimination of any kind.
- Publishing other people's private information.
- Sexualised language or attention.
- Spam, or repeatedly pushing a request after a maintainer has answered it.

## Enforcement

Maintainers may edit or delete comments, close issues, lock threads, and block people who break these rules. For
serious cases, a maintainer will remove the person from the project's spaces without warning.

## Reporting

To report a problem, contact the maintainer, [@Gauravasawa](https://github.com/Gauravasawa), using the contact
details on their GitHub profile. Reports are treated as confidential, and the reporter's identity is not shared
without consent.

This text is a short project-specific statement written in the spirit of the
[Contributor Covenant](https://www.contributor-covenant.org). If the project grows and gets more maintainers, adopt
the full Contributor Covenant text and add a dedicated reporting address.
